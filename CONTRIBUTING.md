# Contributing

This is a framework, not a codebase, so the useful contributions are mostly editorial.

**Especially welcome**

- A failure mode we have not named, with enough detail to be recognisable
- A sector where a stage does not fit, and why
- Corrections — if something here is wrong, say so plainly

**Please avoid**

- Vendor or product recommendations. The framework is deliberately stack-agnostic.
- Confidential material from your own employer. Anonymise, as we have.

Open an issue first for anything substantial, so we can agree the shape before you write it.
